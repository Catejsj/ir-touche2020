[2] THE THREE MODELS

    BOOLEAN
      A document matches if it contains query terms. Pure set
      membership: no weighting, no notion of degree.
      We use OR, not AND. With a 2-3 term query, AND over a 60,000
      document collection returns a handful of documents or none at
      all, and a system that returns nothing cannot be evaluated.
      To compare it against ranked models we order by COORDINATION
      LEVEL - the number of distinct query terms present. This is
      already a concession: real Boolean retrieval returns an unordered
      set, and every ranking metric assumes an order. We state it
      rather than pretend Boolean is a ranking model.

    VECTOR SPACE MODEL
      Document weight  (1 + log tf) x idf
      Query weight     (1 + log qtf) x idf
      Similarity       cosine = dot product / document vector length
      The log dampens term frequency; idf rewards rare terms; the
      cosine removes length. A 4,000-word argument and a 40-word one
      are judged on direction, not size.

    BM25
      k1 = 1.2  how fast term frequency saturates
      b  = 0.75  how hard long documents are penalised
      idf = log(1 + (N - df + 0.5) / (df + 0.5))
      Unlike the VSM, BM25 does not normalise length away completely -
      it compares each document against the collection average. Given
      this corpus (median 127 words, mean 300, max 16,162) that
      difference is the main reason to expect the two to diverge.
